## 1. Primary Screenshots

### Screenshot 1: Web Application Overview
- **Filename:** `01-gallery-and-player.png`
- **Resolution:** 1920 × 1080 px
- **Alt Text:** *Earth Jukebox web application showing the interactive map viewer, moving playhead, audio controls, and the Jukebox gallery.*
- **Description:** Depicts the full two-column layout on desktop: Left column contains the selected NASA Earth visualization with a live-synced playhead and transport controls; right column displays the multi-tab panel open to the Jukebox gallery.

### Screenshot 2: Colorbar Extraction & Legend Assist
- **Filename:** `02-legend-editor.png`
- **Resolution:** 1920 × 1080 px
- **Alt Text:** *Interactive bounding box editor highlighting the NASA legend colorbar with numeric dimension controls.*
- **Description:** Illustrates the canvas bounding box editor. The user has isolated the colorbar; the right-hand panel shows the parsed metadata: minimum value (-4.0 °C), maximum value (+4.0 °C), units, and the "Suggest colorbar" auto-detection assist button.

### Screenshot 3: Interactive Explore Mode
- **Filename:** `03-explore-mode-active.png`
- **Resolution:** 1920 × 1080 px
- **Alt Text:** *Explore mode active with focused grid cell, keyboard navigation instructions, and ARIA announcement tooltip.*
- **Description:** Highlights a specific grid cell at latitude band 2, column 24. A high-contrast reticle marks the cell, while an announcement bubble reads: *"2.4 °C anomaly. Band 2 of 5, column 24 of 48."*

### Screenshot 4: Technical Fidelity Panel
- **Filename:** `04-fidelity-panel.png`
- **Resolution:** 1920 × 1080 px
- **Alt Text:** *Fidelity panel showing High confidence badge, 0.32% RMSE inversion accuracy, and 0.99 round-trip correlation.*
- **Description:** Close-up of the Fidelity tab showing the green "High Confidence (0.98)" quality badge, Level 1 inversion error metric, Level 2 Score round-trip correlation ($r = 0.9914$), and Level 3 YIN pitch-tracking score ($r = 0.9946$).

### Screenshot 5: Cultural Skins Selection
- **Filename:** `05-cultural-skins-dropdown.png`
- **Resolution:** 1920 × 1080 px
- **Alt Text:** *Skin selector menu showing Neutral, Hindustani Raga (Bhairav), and Sri Lankan (Hewisi) options.*

### Screenshot 6: Multi-Frame Time Mode
